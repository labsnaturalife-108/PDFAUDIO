# 🎙️ AudioBook Studio — Fish Audio S2

Автономное приложение для преобразования книг и текстов из **PDF** и **TXT** в выразительную аудиокнигу с клонированием вашего голоса через нейросеть **Fish Audio S2**.

Приложение переносит и значительно расширяет функционал n8n workflow:
- 📖 **Парсинг PDF / TXT** с автоматической очисткой от артефактов верстки и переносов.
- ✍️ **Словарь ударений и фонетики** (с поддержкой санскритских имен, правил для букв «е»/«ё» и сохранением регистра).
- 🧩 **Умный чанкинг**: разделение текста по границам предложений на блоки заданной длины.
- ⚡ **Fish Audio S2 Client**: отправка референсного аудио (base64) и текста, повтор упавших чанков (Retry), кэширование результатов.
- 🎚️ **FFmpeg Audio Stitcher**: склейка фрагментов с регулируемой паузой, нормализация громкости (`loudnorm`) и экспорт в **WAV** / **MP3**.
- 🖥️ **Web UI Studio**: современный интерфейс с предпросмотром текста, почанковым прослушиванием, визуальным редактором словаря и менеджером голосов.
- 💻 **CLI режим**: возможность пакетной конвертации файлов напрямую из терминала.

---

## 🚀 Быстрый запуск

### 1. Запуск Web-студии
```bash
./start.sh
# Или:
python3 cli.py server --port 8088
```
После запуска откройте в браузере: **`http://127.0.0.1:8088`**

### 2. Консольная конвертация (CLI)
```bash
# Конвертировать PDF в MP3:
python3 cli.py convert /path/to/book.pdf --output audiobook --format mp3

# Проверить связь с сервером Fish Audio:
python3 cli.py check
```

```

├── config.py             # Настройки путей, URL Fish Audio и дефолтных параметров
├── extractor.py          # Модуль чтения и очистки текста из PDF / TXT
├── stress_dict.py        # Обработчик словаря ударений с сохранением регистра
├── chunker.py            # Интеллектуальный чанкер по предложениям
├── voice_manager.py      # Менеджер эталонных записей голоса (.wav + текст)
├── tts_client.py         # HTTP-клиент к локальному серверу Fish Audio S2
├── audio_merger.py       # FFmpeg сборщик (паузы, loudnorm, конвертация)
├── pipeline.py           # Оркестратор полного цикла синтеза
├── server.py             # FastAPI сервер API и статики
├── cli.py                # Консольная утилита управления
├── static/               # Веб-интерфейс (HTML, CSS, JS)
│   ├── index.html
│   ├── style.css
│   └── app.js
├── data/
│   ├── dictionaries/     # JSON файлы словарей ударений
│   └── voices/           # Профили и аудиозаписи референсных голосов
```

## ⚙️ Настройки и параметры генерации

- **Fish Audio URL**: по умолчанию `http://127.0.0.1:8020/generate` (настраивается в UI или через переменную окружения `FISH_AUDIO_URL`).
- **Референс по умолчанию**: `/Users/jeka/fish-audio-s2/voice/reference.wav`.
- **Loudnorm**: нормализация аудиокниг по стандарту EBU R128 (`I=-16:TP=-1.5:LRA=11`).
